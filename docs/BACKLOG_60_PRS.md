# خطة الـ60 PR — كل PR إضافة حقيقية للمنتج

**القاعدة:** كل PR = فرع + commit + اختبار حقيقي + معيار قبول قابل للتحقق. لا PR بلا أثر يراه المستخدم أو يحمي بياناته.

## E — التشفير والخصوصية عند الراحة (12 PR) 🔐

| ID | الإضافة للمنتج | معيار القبول |
|---|---|---|
| E01 | `SecureKeyStore` موحّد (fake للاختبار + OS secure storage للإنتاج) | لا مفتاح في DB/سجلات؛ اختبار fake يكشف أي تسريب |
| E02 | اشتقاق مفتاح من passphrase بـ Argon2id (pure Dart) | اختبار متجهات معروفة + زمن مشتق معلن |
| E03 | **نسخة احتياطية مشفّرة `.tmewia`**: AES-256-GCM بترويسة+مانيفست | ملف مشفّر لا يحتوي أي نص مقروء (grep يثبت) |
| E04 | استعادة + تحقق: passphrase خطأ، ملف معدَّل، مانيفست مختلف | 3 رموز خطأ آمنة، صفر كتابة عند الفشل |
| E05 | أداة `tool/vault.dart` (encrypt/decrypt round-trip) | CLI اختباري ناجح + hash مطابق |
| E06 | مخزن وسائط مشفّر (بايتات المرفقات مشفّرة، الميتاداتا لا) | قراءة بايت مشفّر لا تعطي JPEG صالحاً قبل الفك |
| E07 | DEK لكل مساحة عمل + KEK على passphrase (wrapping) | فكّان مختلفان بنفس passphrase لا يفتحان بيانات بعض |
| E08 | تدوير المفتاح/تغيير passphrase بلا إعادة تشفير كل شيء | إعادة لف DEK فقط + اختبار فتح بالقديم يفشل |
| E09 | تشفير DB عند الراحة (SQLCipher) مع كشف القدرة و fallback | إن غاب libsqlcipher: حالة UI صريحة لا ادعاء تشفير |
| E10 | بحث فوق حقول مشفّرة عبر blind index (HMAC tokens) | البحث يرجع نفس النتائج بعد التشفير |
| E11 | محو آمن لمساحة العمل + شرح حدود SSD | لا بقايا ملفات؛ نص صريح عن حدود المحو |
| E12 | حارس تنقيح السجلات | اختبار يثبت صفر نص رسالة/مفتاح في أي log |
